## Продолжение в Claude Code

Claude Code — не чат с загрузкой файлов, а инструмент, который работает
напрямую с git-репозиторием или с файлами на реальной машине. Проще всего:

1. Распакуй этот архив.
2. Создай пустой репозиторий на GitHub, залей туда содержимое архива
   (`git init`, `git add .`, `git commit`, `git push`).
3. В приложении Claude → вкладка **Code** → **New session** → облачная
   сессия → выбери этот репозиторий.
4. Первым сообщением попроси Claude прочитать `HANDOVER.md` в корне —
   дальше контекст восстановится так же, как при чтении этого файла в чате.

Если вместо GitHub есть свой компьютер с установленным Claude Code (`claude`
в терминале) — работает и «Add device»: запусти `claude` в папке с
распакованным архивом, включи Remote Control (`/config` → Remote Control,
или команда `claude remote-control`), и машина появится в приложении как
устройство.

## Что это за мод

Ванильные деревни заменяются на **растущие**: игрок находит крошечное
поселение (ратуша + костёр + один дом) и вкладывает ресурсы в сундук
ратуши, чтобы поднимать её по уровням. Деревня физически достраивается
вдоль одной прямой улицы, приходят ремесленники с квестами, на поздних
уровнях появляются стены, башни и стража.

Ключевой принцип: **гармония с ванилью**. Только ванильные блоки и
текстуры, ничего оверпаверного, экономика игрока не ломается.

- **Замена ванильного спавна деревень** — сейчас деревня ставится только
  Колоколом-Оракулом. Автогенерация в мире не реализована.
- **Другие биомы** — только равнины. Материалы уже вынесены в таблицы

  палитру на биом, чертежи переиспользуются.
- **Улучшение домов ремесленников через квесты** — договорились делать
  в следующей версии. Задел есть: каждая `build*`-функция возвращает
  «форму» дома с координатами (`f1,f2,sMin,sMax,height,doorForward,midS`),
  по ней можно достроить второй этаж или пристройку.
- **Репутация деревни** — отклонено пользователем.
- **Ночной колокол с сообщениями игроку** — отклонено, оставлено только
  поведение жителей.
- **Уровни 11–15** — задумывались изначально, сейчас потолок 10.
- **Караваны между деревнями** — идея из ранних обсуждений, не начата.

### Локальная система координат (важно понять первым делом)

Все здания описываются не в мировых координатах, а в **локальных
относительно деревни**:

- `forward` — вдоль главной улицы от ратуши
- `side` — поперёк улицы (минус = левый участок, плюс = правый)
- `up` — высота над улицей

`toWorld(origin, facing, forward, side, up)` переводит это в мир с учётом
того, в какую сторону смотрит деревня (`facing`: 0=+X, 1=−X, 2=+Z, 3=−Z).

Благодаря этому каждое здание пишется один раз и корректно ставится при
любом направлении улицы.

### Планировка улицы (не нарушать!)

```
side -15  ← линия стены
side  -3..-9   левые участки (дома)
side  -2       фонарные столбы
side  -1..1    дорога
side   2       фонарные столбы
side   3..9    правые участки (дома)
side  15  ← линия стены
```

Дома начинаются с `|side| = 3` — если поставить ближе, стена дома
воткнётся в фонарный столб (эта ошибка уже была допущена и исправлена).

### Как добавить новый уровень

1. Написать `buildXxx()` в `builder.js` (взять любую существующую как образец).
2. Добавить запись в `LEVELS` в `levels.js`.
3. Прогнать тесты.

Всё остальное — требования у старосты, выравнивание грунта, спавн NPC,
табличка — подхватится автоматически, потому что читает из `LEVELS`.

## Тестовый стенд — читай обязательно

В `tests/` лежит **эмулятор Bedrock API** на Node.js. Он позволяет
прогонять всю логику мода без игры. Это критично: я не могу запустить
Minecraft, поэтому без тестов правки делаются вслепую.

### Запуск

```bash
cd tests
cp -r ../GrowingVillages_BP/scripts ./scripts   # синхронизировать код
for f in lint run integration geometry roof fixes features polish; do
  echo "=== $f ==="; node $f.mjs
done
```

### Наборы

| Файл | Что проверяет |
|---|---|
| `lint.mjs` | Загрузка пака, схема предметов, манифесты |
| `run.mjs` | Логика уровней, сундук, квесты, скидки |
| `integration.mjs` | Целая деревня: дома не сносят друг друга |
| `geometry.mjs` | Стены без дыр, полы проходимы |
| `roof.mjs` | Крыши без просветов |
| `fixes.mjs` | Двери, рельеф, привязка NPC, големы |
| `features.mjs` | Укрепления, производство, баланс, квесты |
| `polish.mjs` | Ремонт големов, табличка, ночь, интерьеры |

Всего ~305 проверок. **Все должны быть зелёными перед упаковкой.**

### Чему стенд НЕ научит

Он проверяет мою логику, но не движок. Не ловит:
- как это выглядит на экране (пропорции, ориентация ступеней)
- правильность ID блоков и имён блок-стейтов
- поведение ванильного ИИ

Это проверяется только реальным тестом в игре и скриншотами.

## Грабли, на которые уже наступили (не наступать снова)

1. **Двери.** В Bedrock 1.21.60+ дверь использует
   `minecraft:cardinal_direction` (строка), а не `direction` (число).
   И дверь — это **два блока**: нижняя половина + верхняя с
   `upper_block_bit: true`. Одна половина = визуально сломанная дверь.

2. **Ранняя инициализация.** Нельзя вызывать `world.*` на верхнем уровне
   скрипта — движок бросает `ReferenceError` и **весь пак падает**.
   Всё стартовое заворачивать в `system.run()`.

3. **Иконка предмета.** `minecraft:icon: {"texture": ...}` устарело,
   нужна просто строка: `minecraft:icon: "shortname"`.

4. **Выравнивание рельефа сносило готовые дома.** Площадку под новый
   участок нельзя чистить широкой полосой через всю улицу. Сейчас два
   узких прохода: отдельно дорога, отдельно свой участок на своей стороне.

5. **Блок-стейты переименовываются между версиями.** Поэтому в `util.js`
   есть `resolveFirst()` — перебирает несколько схем и берёт первую,
   которую движок принял. Использовать её для всего, что имеет ориентацию.

## Баланс производства (не ломать)

Фермер и шахтёр специально сильно ограничены, чтобы игрок не бросил
собственный майнинг и фермерство:

- **Дневной лимит**: фермер 12 пшеницы, шахтёр 6 предметов за игровой день
- **Лимит склада**: работа останавливается при 64 / 32 предметах
- **Шанс на такт**: шахтёр работает не каждый цикл
- **Алмазы шахтёр не производит никогда**

Тест `features.mjs` проверяет эти границы. Если поднимать числа — сначала
обсудить, это прямое влияние на экономику игры.

## Установка мода

1. Открыть `.mcaddon` — iOS предложит открыть в Minecraft.
2. В настройках мира включить **оба** пака (Behavior + Resource).
3. Мир на равнинах, включить чит-режим не обязательно.
4. В креативе взять «Колокол-Оракул деревни», встать на открытом месте,
   посмотреть в сторону будущей улицы, использовать предмет.
5. Староста в ратуше — жёлтое имя. Клик по нему: требования и постройка.
6. Ремесленники: **обычный тап — квест**, **тап с приседанием — торговля**.
